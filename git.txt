Quick setup — if you’ve done this kind of thing before

Get started by creating a new file or uploading an existing file. We recommend every repository include a README, LICENSE, and .gitignore.
…or create a new repository on the command line

echo "# playwright" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin git@github.com:sayamc/playwright.git
git push -u origin main

…or push an existing repository from the command line

git remote add origin git@github.com:sayamc/playwright.git
git branch -M main
git push -u origin main

git branch -r				// แสดงรายชื่อ remote branch ทั้งหมด
git branch -a				// แสดงรายชื่อ branch ทั้ง local branch และ remote branch
git branch [ชื่อ branch]			// สร้าง branch ใหม่
git checkout -b "new-branch-name"	// create new branch
git branch -M [ชื่อ branch] 		// เปลี่ยนชื่อโดยที่ไม่สนใจว่า branch นั้นจะมีอยู่แล้วรึเปล่า
git checkout "branch-name"		// git checkout หรือ git switch ; change to branch
git branch -D [ชื่อ branch]		// ลบ branch โดยที่ไม่จำเป็นต้อง merge ลบทิ้งไปเฉยๆเลย
git diff				// check different data in all file.

git checkout master			// checkout to master/origin
git merge my_new_branch			// ไฟล์ที่อยู่ใน my_new_branch ก็จะเข้ามาอยู่ใน master/origin แล้ว
